# Debug

1. Read the full traceback or the failing behaviour the user pasted.
2. Explain the root cause in at most 2 simple sentences.
3. Propose the smallest possible fix (a few lines, not a rewrite).
4. Apply it, run it again, and show the result.
5. If it is a Selenium failure, also check: locator, missing wait, iframe, overlay, stale element. If it is an API failure: status code, URL, auth, timeout, non-JSON body.
