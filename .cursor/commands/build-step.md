# Build one step

1. Read `REQUIREMENTS.md` and the plan. Identify the next unfinished step.
2. Implement ONLY that step. Max about 60 lines of new code. Reuse existing files in `src/` where possible.
3. Do not add features that are not in the step.
4. Run the code yourself if you can, and show the real output.
5. Give the exact command for the user to run, and what correct output looks like.
6. Tick the finished items in `REQUIREMENTS.md`. Stop and wait.
